# Agenda · Escuela de Debate Comillas

Calendario y lista de actividades (Debate, MUN, Diplomacia, Otros) con tareas por actividad y día de entrega.

- `index.html`: la aplicación (se publica con GitHub Pages).
- `supabase.sql`: crea las tablas, la seguridad y el tiempo real en Supabase.

Para configurarla, rellena `SUPABASE_URL` y `SUPABASE_KEY` al principio del `<script>` final de `index.html`.
Los usuarios se crean en Supabase → Authentication → Users.
